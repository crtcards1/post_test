man
===

File read
---------

[Sudo]
    man /path/to/input-file
    The file is shown somehow formatted and displayed in the default pager.

[SUID]
    man /path/to/input-file
    The file is shown somehow formatted and displayed in the default pager.

[Unprivileged]
    man /path/to/input-file
    The file is shown somehow formatted and displayed in the default pager.
