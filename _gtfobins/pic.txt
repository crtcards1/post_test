pic
===

File read
---------

[Sudo]
    pic /path/to/input-file
    The output is prefixed with some content.

[SUID]
    pic /path/to/input-file
    The output is prefixed with some content.

[Unprivileged]
    pic /path/to/input-file
    The output is prefixed with some content.

    pic -U

[SUID]
    pic -U

[Unprivileged]
    pic -U
