mosquitto
=========

File read
---------

[Sudo]
    mosquitto -c /path/to/input-file
    The file is actually parsed and the first wrong line (ending with a newline or a null character) is returned in an error message.

[SUID]
    mosquitto -c /path/to/input-file
    The file is actually parsed and the first wrong line (ending with a newline or a null character) is returned in an error message.

[Unprivileged]
    mosquitto -c /path/to/input-file
    The file is actually parsed and the first wrong line (ending with a newline or a null character) is returned in an error message.
