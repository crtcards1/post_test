dig
===

File read
---------

[Sudo]
    dig -f /path/to/input-file
    Each input line is treated as a lookup query for the `dig` command and the output is corrupted with the result or errors of the operation.

[SUID]
    dig -f /path/to/input-file
    Each input line is treated as a lookup query for the `dig` command and the output is corrupted with the result or errors of the operation.

[Unprivileged]
    dig -f /path/to/input-file
    Each input line is treated as a lookup query for the `dig` command and the output is corrupted with the result or errors of the operation.
